# Support and citation

## Getting help

Questions, bug reports, and feature requests are welcome on the GitHub issue tracker:

[https://github.com/MHH-Bioinformatics-Hematology/vardictcpp/issues](https://github.com/MHH-Bioinformatics-Hematology/vardictcpp/issues)

When reporting a problem, please include the vardictcpp version (`vardictcpp --version`), the exact
command line, and the reference and platform (operating system and CPU architecture).

## Project links

- Developer group: [MHH Bioinformatics and Hematology](https://mhh-bioinformatics-hematology.github.io/)
- vardictcpp source: [github.com/MHH-Bioinformatics-Hematology/vardictcpp](https://github.com/MHH-Bioinformatics-Hematology/vardictcpp)
- Galaxy wrapper: [github.com/MHH-Bioinformatics-Hematology/galaxytools](https://github.com/MHH-Bioinformatics-Hematology/galaxytools)

## Contributing

Contributions are welcome. Please open an issue to discuss a change before submitting a pull request,
and make sure the parity test suite (`bash test/run_tests.sh`) still passes.

## Citing vardictcpp

If you use vardictcpp in your research, please cite the software and the original VarDict method:

- Wolff J. vardictcpp: a C++/htslib reimplementation of the VarDict variant caller.
  [https://github.com/MHH-Bioinformatics-Hematology/vardictcpp](https://github.com/MHH-Bioinformatics-Hematology/vardictcpp)
- Lai Z, Markovets A, Ahdesmaki M, et al. VarDict: a novel and versatile variant caller for
  next-generation sequencing in cancer research. *Nucleic Acids Research*. 2016;44(11):e108.
  doi:10.1093/nar/gkw227

RRID: SCR_028800.
